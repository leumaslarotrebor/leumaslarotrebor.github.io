# Samuel Oral Robert V — Portfolio

Personal portfolio site, built with React + Vite + Tailwind.

Live: https://leumaslarotrebor.github.io

## Stack
- React 19 + Vite
- Tailwind CSS
- GSAP / AOS / Framer Motion for animation
- Three.js (`@react-three/fiber`, `@react-three/drei`) for the 3D lanyard/card elements

## Run locally

```bash
git clone https://github.com/leumaslarotrebor/leumaslarotrebor.github.io.git
cd leumaslarotrebor.github.io
npm install
npm run dev
```

## Build & deploy

```bash
npm run build
npm run deploy
```

`npm run deploy` pushes the built `dist/` folder to the `gh-pages` branch via the `gh-pages` package. GitHub Pages (Settings → Pages) is configured to serve from that branch.
